# 2023post.com

Static site for 2023 Post LLC, hosted on GitHub Pages.

- `index.html` is the whole site (styles and script are inline).
- `img/` holds the photos and posters.
- Logo source files and brand notes live in the separate logo package (2023Post-Logo.zip).

To change copy, edit `index.html` and commit. GitHub Pages republishes in about a minute.
